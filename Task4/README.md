# Задание 4

1. Требуется ли ему своё хранилище данных?
    * Свое хранилище данных нужно. Мы можем сохранять какую-либо инфу и также использовать Transactional Outbox (опционально)


2. Какой API он предоставляет core-app?
   * GET /osago/{request_id}/status - информация по заявке
   * POST /osago/create {userId, ...data} - пользователь и заполненные им данные по заявке
   

3. Определите средство интеграции между сервисами core-app и osago-aggregator:
   * Средство интеграции похоже на ins-comp-settlement <-> core-app, потому что, по сути, это тоже агрегатор
   core инициирует рест запрос оформления заявки, затем подписывается на события этого сервиса через брокер. 


4. Подумайте над API для веб-приложения в core-app. Определите средство интеграции между веб-приложением и core-app. 
Если будете использовать средство, отличное от REST, отразите интеграцию новой стрелкой.
   * Далее, через WebSocket, клиент получает инфу.

5. Паттерны отказоустойчивости:
   * osago-aggregator -> страховые:	Circuit Breaker
   * core-app -> osago-aggregator:	Rate Limit
